Darbu veicu secībā, kādā doti soļi uzdevumu dokumentā, un to veicu ar mērķi padarīt to cik vien funkcionējošu cik spēju.

Mēģināju pēc iespējas vairāk no atmiņas, taču vietām nācās smagi paļauties uz jūsu dotajiem mācibu materialiem un VS Code iebūvētās palīdzības sistēmas.

Noformējums tika veidots ļoti minimāls, jo slikti atceros CSS, par cik to praktiski vairs neizmantojam stundās.
